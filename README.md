# Sistema Nacional de Gestión de Recursos y Riesgos

API REST del Sistema Nacional de Gestión de Recursos y Riesgos.

## Tecnologías

- Java 21
- Spring Boot 4.1.1
- Maven
- PostgreSQL 15
- Docker
- Docker Compose

## Ejecución local

### Requisitos

- Docker
- Docker Compose

### Configuración

Agregar el archivo `.env` en la raíz.

URL API: https://sistema-nacional-api-wqib.onrender.com
